# Budget Model — Quote-Based, Scenario Friendly

This bundle intentionally does not invent current vendor prices. Enter local quotes and staffing rates, then compare three scenarios.

| Cost lane | Low-tech pilot | Standard school | Immersive launch |
|---|---|---|---|
| Software / hosting | Existing web hosting or approved district platform | Managed deployment + support | Managed deployment + integrations |
| Devices | Existing devices | Gap-filling devices | Gap-filling + shared display hardware |
| Displays/signage | Printed signs | Printed + digital displays | Large-format/projected environments |
| Audio/visual | Existing PA/projector | Upgraded assembly AV | Projection mapping / responsive AV |
| Staff design time | Small pilot team | Department/grade teams | Cross-school design/production team |
| Professional learning | Short onboarding | Facilitated training + coaching | Training + coaching + launch rehearsals |
| Accessibility | Review existing assets | Formal accessibility test | Formal test + alternative launch experience |
| Privacy/security | Internal review | Formal privacy/security assessment | Assessment + integrations/identity review |
| Evaluation | Baseline + simple dashboard | Pre-specified pilot evaluation | External/independent evaluation option |
| Contingency | 10–15% planning reserve | 10–15% | 15–20% for event/AV complexity |

## Formula
**Total pilot cost = one-time setup + staff release/design time + training + hardware/signage + privacy/security/accessibility review + evaluation + contingency + recurring software/hosting.**

## Cost discipline
Prefer reversible investments first: curriculum/quest templates, staff capability, print signage, browser-based tools, and measurement design. Treat spectacular AV as an optional launch amplifier rather than the core intervention.
