# Teacher Onboarding Kit

## 45-minute first session
1. **Purpose (5 min):** game mechanics are feedback and narrative scaffolds, not a substitute for pedagogy or relationships.
2. **Core loop (10 min):** learning objective → quest → evidence → feedback → XP/mastery → reflection/next quest.
3. **Recognition (10 min):** award observable behaviors or work products; prefer specific feedback over generic points.
4. **Repair (10 min):** behavior incidents are support/safety events, not entertainment. Do not publicly remove XP, shame students, or make peers responsible for punishment.
5. **Accessibility + choice (5 min):** equivalent non-gamified view, reduced motion, keyboard/screen-reader support, accommodations preserved.
6. **Practice (5 min):** convert one existing lesson into a quest using the template below.

## Quest template
- Learning objective / standard
- Student-facing mission
- Success criteria
- Evidence students submit or demonstrate
- Choice of pathways or roles
- Cooperation opportunity
- Feedback checkpoint
- XP/mastery recognition rule
- Accessibility alternatives
- Estimated time
- Materials
- Reflection / transfer question

## Recognition rules
Use small, legible, reversible awards. Attach achievement provenance: what happened, which criterion was met, who verified it, and when. Avoid high-frequency point inflation; use anti-Goodhart checks when the measured action can be spammed.

## Five-minute daily routine
Review today's two or three quests, announce one cooperative target, recognize specific demonstrated progress, capture only the minimum necessary data, and close with a reflection or next-step cue.

## When a student opts out of the game aesthetic
Keep objectives, assignments, accommodations, feedback, and mastery evidence identical. Replace fantasy labels/animations with plain learning terminology. Opting out should not reduce opportunity, status, or rewards tied to real educational accomplishments.
